### `├──` CONTACT PIPELINE

Every submission — web form or CLI `contact` command — is validated server-side and relayed to the owner's Gmail via **[Resend](https://resend.com)**, subject-lined `Coming from portfolio - Talha Qureshi - <name>` with **Reply-To** wired to the visitor.

```bash
# one-time activation (already live in production):
$ resend.com → sign up with your Gmail → API Keys → create
$ vercel env add RESEND_API_KEY production     # paste re_... key
$ vercel deploy --prod
```
